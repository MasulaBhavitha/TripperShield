# AI Usage

This project was developed via a Laravel 11 scaffold and iterative code implementation guided by the assignment brief and validation runs.

## Scope of AI assistance

- Scaffolded the Laravel application and dependency setup
- Implemented the policy domain, API endpoints, and workflow logic
- Identified and corrected pricing and lifecycle bugs during validation
- Wrote the feature tests that cover the required reliability scenarios

## Important notes

- Manual validation was used to confirm the premium rule and lifecycle state transitions.
- The underlying business logic remains in the application code, with the database and tests as the source of truth for behavior.
- This file documents usage of AI-assisted development and the project’s intended implementation boundaries.
